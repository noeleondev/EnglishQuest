# 🎮 English Quest (A0 a C2)

**English Quest** es una plataforma web gamificada diseñada para la práctica y repaso de vocabulario y gramática en inglés. El proyecto está construido con un enfoque en la adicción positiva: sistema de XP, rachas, escudos y progresión visual para mantener la motivación.

> **⚠️ Nota importante:** Este proyecto **NO** es un curso de inglés completo. Es una herramienta de **práctica**. El material teórico (vocabulario y reglas gramaticales) está integrado como una "Biblioteca" dentro de cada zona para que puedas repasar antes de jugar.

## 🚀 Características

- **Nivel 0 Completado:** 17 zonas jugables (11 de vocabulario y 6 de gramática) que cubren desde el alfabeto hasta el verbo To Be y plurales.
- **Sistema de Progresión:** 4 fases por zona (Reconocimiento, Producción, Inverso y JEFE final).
- **Biblioteca Integrada:** Cada zona incluye una ventana de teoría con tablas de vocabulario y explicaciones gramaticales sencillas.
- **Multi-usuario:** Diferentes perfiles pueden guardar su progreso en el mismo equipo.
- **6 Temas Visuales:** Cambia la apariencia de la interfaz (Cyberpunk, Halloween, Navidad, etc.).

## 🛠️ Tecnologías

- **Backend:** Python + Flask
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Arquitectura:** Modular (cada zona tiene sus propios datos y motor de juego).
